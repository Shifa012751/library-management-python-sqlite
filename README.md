# 📚 Library Management System – Python + SQLite

A simple and efficient **Library Management System** built using Python and SQLite.  
This project allows users to manage books, members, and transactions (issue/return of books).

---

## 🚀 Features

### 📘 Book Management
- Add new books  
- Update book details  
- Delete books  
- Search books  
- Track total & available quantity  

### 👤 Member Management
- Add members  
- Update member data  
- Delete members  
- View all members  

### 🔁 Transaction Management
- Issue a book  
- Check due date  
- Prevent issuing when unavailable  
- Return a book  
- Auto-update availability
